【中考录取查询网站 · 后期修改说明】（零基础照做）

======== 一、改录取数据（最常改）========
用记事本打开 data.js，找到这一大段：
    window.DICT = {
      ...很多条...
    };
每条是一对，格式固定：
    "名单文字（里面含考生姓名）": "对应的学校/批次名",
添加新数据：在最后的 }; 前面，加一行。

==== 三个坑（踩了页面会白屏）====
1. 键和值都用【英文双引号 "】，不能用中文引号“”。
2. 每条之间用英文逗号 , 隔开。
3. 【最后一条后面不要逗号】。

======== 二、改作者简介（你自己改，不用找人）========
★ 你唯一要改的文件就是：about.js
★ 不管用本地双击 index.html，还是传到 GitHub，简介都只认 about.js。
操作步骤：
  1) 用记事本打开 about.js（和 index.html 在同一个文件夹里）。
  2) 只改这一行里【两个反引号 ` 之间】的文字，直接回车换行就行：
        window.ABOUT = `这里写你的简介，回车换行即可`;
  3) 保存（Ctrl+S），回到浏览器按 F5 刷新，简介立刻变成你写的。
⚠ 别删掉开头的 window.ABOUT = ` 和结尾的 `; ，否则会出错。
⚠ about.txt / sync.bat 已经作废删掉了，不用再管。

======== 三、改完怎么生效 ========
【情况 A：电脑上双击 index.html 本地看】
  改完文件 → 浏览器按 F5 刷新，立刻生效。
【情况 B：已传到 GitHub 让全网访问】
  把改好的 data.js / about.js / index.html 重新上传覆盖 → 等 1~2 分钟刷新。

======== 四、记住就这三点 ========
- 简介只动 about.js；数据只动 data.js；index.html 一般不用动。
- 英文双引号、英文逗号、末条无逗号 —— 白屏就查这三条。
- 纯静态、无后台，改完刷新（或重新上传）才生效，不会自动变。
